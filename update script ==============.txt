Client-side Image Compression: Uploaded profile photos and shared images in chat will be compressed on the fly (via a canvas-based resizer) to under 15KB. This ensures socket messages are tiny, lightweight, and never exceed Socket.io's default 1MB limits.
E2EE WebRTC Calls: Real WebRTC audio/video call connections will be established using the simple-peer library. Socket.io on the server will act purely as the signaling server relaying offers, answers, and ICE signals.
Call History Recording: The call duration is calculated on the server and saved permanently to database.json. It will show up in the chat window of both accounts (e.g. 📞 Call ended · 3m 14s) in real-time when a call ends.
